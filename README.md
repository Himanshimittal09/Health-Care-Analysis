# 🏥 Healthcare Analytics Dashboard | Power BI

An interactive **Power BI Healthcare Analytics Dashboard** built to analyze healthcare operations, patient visits, billing performance, treatment costs, insurance coverage, referral sources, and departmental performance.

## 📊 Features
- KPI Cards for key healthcare metrics
- Patient, Billing & Treatment Cost Analysis
- Insurance Coverage & Out-of-Pocket Analysis
- Department & Referral Source Performance
- Interactive Maps, Charts, Treemaps & Filters
- Data Cleaning with Power Query
- Data Modeling & DAX Measures

## 🛠️ Tools & Technologies
- Power BI
- Power Query
- DAX
- Data Modeling

## 📈 Dashboard Insights
The dashboard provides actionable insights to support data-driven decision-making by tracking operational performance, patient trends, financial metrics, and departmental efficiency.
